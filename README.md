🔥 Air Heater Monitoring System

This project is an IoT-based air heater monitoring system designed to collect, store, and process temperature data efficiently. The backend is implemented using Django, with a focus on reliability and asynchronous data handling.

Temperature data generated by the air heater sensors is stored in a PostgreSQL database. To handle background processing and time-consuming tasks, Celery is integrated alongside Redis as the message broker. This architecture allows the system to process sensor data asynchronously and remain responsive under load.

The project emphasizes clean backend structure, proper task separation, and scalability for IoT-based applications.

🛠️ Tech Stack

- Backend: Django  
- Database: PostgreSQL  
- Asynchronous Tasks: Celery  
- Message Broker / Cache: Redis  
- Domain: IoT, Temperature Monitoring, Air Heater Systems  

✨ Features

- Background processing of temperature data  
- Reliable data storage using PostgreSQL  
- Asynchronous task execution with Celery and Redis  
- Designed for IoT-based monitoring systems
